**How QALAB uses it:** the lessons are the team's own explanations and examples, built on the syllabus structure and terms (the "basis for articles" condition). **Open points for a human to decide:**

1. QALAB is a personal learning platform. If it ever becomes commercial, or is presented as ISTQB exam preparation, the "non-commercial" and "accredited training provider" conditions must be reviewed again, possibly with ISTQB.

3. ISTQB® is a registered trademark: use the name only to identify the source.
